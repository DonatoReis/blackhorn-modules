# Security Policy

## Supported versions

Security fixes are applied to the latest release and the default branch.

## Reporting a vulnerability

Do not open a public issue for a vulnerability in BLACKHORN or its modules.
Use GitHub private vulnerability reporting in the repository Security tab.
Include reproduction steps, affected versions, impact, and a proposed fix when
available.

Do not include real target data, credentials, tokens, or personal information.

## Authorized use

BLACKHORN is intended only for systems you own or are explicitly authorized to
assess. Contributors must keep tests local and deterministic. The maintainers
do not authorize or endorse unlawful access, disruption, or data collection.
